Methodology

Our investigation into global media coverage patterns combines multiple data sources to reveal disparities in how conflicts are reported. We analyzed over 2.5 million news articles from the GDELT Project, cross-referenced with fatality data from ACLED's conflict database, spanning January 2024 through December 2025.

The methodology involves several key steps: data extraction, normalization, sentiment analysis, and statistical comparison. Below, we detail the technical implementation of our data pipeline and analytical framework.

query.sql 
-- Extract media coverage data with aggregated metrics
SELECT 
    country_name,
    COUNT(DISTINCT article_id) AS total_mentions,
    AVG(sentiment_score) AS avg_sentiment,
    PERCENTILE_CONT(0.5) WITHIN GROUP 
        (ORDER BY sentiment_score) AS median_sentiment,
    DATE_TRUNC('week', publication_date) AS week
FROM gdelt_articles
WHERE 
    publication_date BETWEEN '2024-01-01' AND '2025-12-31'
    AND conflict_related = TRUE
GROUP BY country_name, week
ORDER BY total_mentions DESC;

The query above extracts weekly aggregated metrics for each country, including total article mentions and sentiment distributions. We normalized coverage intensity by population and conflict severity to identify systematic biases in reporting patterns.

After data extraction, we merged coverage metrics with fatality counts from ACLED. The resulting dataset contains 1,847 country-week observations across 58 conflict-affected nations. The table below shows a sample of our processed data:

Notice the stark disparity: Sudan recorded more fatalities than Ukraine in this sample week, yet received less than 6% of the media coverage. This pattern persists across our entire dataset, revealing systematic underreporting of conflicts in Africa and Southeast Asia.

To quantify these disparities, we developed a coverage-to-casualty ratio and applied statistical clustering to identify patterns. The Python implementation below demonstrates our analytical approach:

analysis.py 
import pandas as pd
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

# Load processed data
df = pd.read_csv('coverage_fatalities.csv')

# Calculate coverage-to-casualty ratio
df['coverage_ratio'] = df['mentions'] / (df['fatalities'] + 1)

# Normalize by population (per 100k inhabitants)
df['normalized_coverage'] = (
    df['mentions'] / df['population']
) * 100000

# Apply log transformation to handle skewness
df['log_mentions'] = np.log1p(df['mentions'])
df['log_fatalities'] = np.log1p(df['fatalities'])

# Standardize features for clustering
scaler = StandardScaler()
features = df[['log_mentions', 'log_fatalities', 'avg_sentiment']]
X_scaled = scaler.fit_transform(features)

# Cluster countries into coverage patterns
kmeans = KMeans(n_clusters=4, random_state=42)
df['cluster'] = kmeans.fit_predict(X_scaled)

# Export results
df.to_csv('analyzed_coverage_patterns.csv', index=False)
